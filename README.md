🛡️ 反詐騙 AI 防護系統
📘 專案簡介

本專案旨在建立一個可實際落地運作的 AI 反詐騙防護系統，整合文字、圖片與語音等多模態資料，結合人工智慧判斷與信任人機制，協助使用者即時辨識詐騙風險、發出警示並促進社群互助。

🎯 專案目標

多模態詐騙偵測

利用螢幕截圖辨識（OCR）、個資去敏化與 AI 判斷模型，分析圖片或文字中是否存在詐騙風險。

將高風險案件即時通知使用者及其「信任人」，降低詐騙受害風險。

語音詐騙分析與防 Deepfake

分析通話錄音，結合語音辨識與深度偽造檢測模型（Deepfake Detection），辨識高風險語音訊息並即時預警。

社群互助防詐平台

結合 APP 功能，讓使用者在偵測疑似詐騙時可即時發出求助通知，由社群共同提供建議與支援。

信任人層級防護機制

引入信任人制度，多層次通知與警示流程，防止衝動匯款或個資外洩。

個人化防詐儀表板

視覺化顯示詐騙事件與防護資訊，協助使用者追蹤風險並強化自我防禦能力。

即時推播與個人化防禦建議

根據使用者行為與儀表板數據，動態推播最新防詐案例與防護建議，達成主動式防禦。
