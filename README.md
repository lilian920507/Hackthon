🛡️ 反詐騙 AI 防護系統



1. 多模態詐騙偵測：
建立一個可實際落地運作的反詐騙服務，透過螢幕截圖的自動辨識（OCR）、個資去敏化與 AI 模型判斷，將高風險案件即時通知使用者指定的「信任人」及當事人，降低詐騙受害風險，並促進社群互助。

2. 語音詐騙分析與偽造防護：
分析通話錄音檔，結合多語言語音識別模型與防 Deepfake 偽造語音檢測機制，判斷語音詐騙風險並即時推播警示。

3. 社群互助防詐平台：
結合 APP 機制，當使用者偵測到詐騙跡象時可即時發送求助通知，由社群共同回應與支援，形成防詐互助網。

4. 信任人層級防護機制：
透過信任人制度，建立多層次的警示與確認流程，提升安全防線，防止衝動匯款或資料外洩。

5. 個人化防詐儀表板：
提供每位使用者專屬的反詐儀表板，將詐騙相關資訊視覺化呈現，協助分析風險、追蹤事件與強化個人防禦。

6. 即時推播與個人化防禦建議：
根據使用者的儀表板數據與行為特徵，動態推播最新防詐資訊與個人化建議，達成主動防禦與教育效果。
